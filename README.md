# Gingersnaps

An Apron compatible system in the spirit of BBSs, newsgroups, and forums.

## Reference:

* [Changelog](CHANGELOG.md)
* [To Do List](TODO.md)

## Usage

```
Usage: gingersnaps [(OPTIONS)]

  An Apron compatible system in the spirit of BBSs, newsgroups, and forums.

Options:

  --mode <MODE>                        Mode to run in (default: server, choices: server, help)

  --cache_dir <DIR>                    Cache directory (default: cache)
  --listen_addr <ADDR>                 IP address and port to listen on (default: 0.0.0.0:17187)

  --help | -h                          Display this help message
  --version | -V                       Display version
```
